# 子機のBLE Wi-Fi設定

## 操作

SOS警報が鳴っていないときに、バッテリーボタン（BUTTON 2）を2秒以上押すと、BLE設定サービスを2分間だけ起動します。アプリの親機検索画面から`COCO-<子機UUID先頭8文字>`を選び、Wi-FiのSSIDとパスワードを送信してください。短押し時の電池残量表示と、SOS中の警報解除操作は維持します。

SSID・パスワードはWi-Fi接続に成功した場合だけNVSへ保存し、次回起動時に再利用します。Wi-Fi接続失敗時は以前に保存したネットワークへの再接続を試みます。認証情報をシリアルログには出力しません。BLE広告は設定操作中だけ行い、設定成功後または2分経過後に停止します。Wi-Fiのモデムスリープも有効にします。

## GATT互換性

親機・アプリの設定プロトコルに合わせ、サービスUUIDと設定・状態Characteristic UUIDを共有します。設定Characteristicへの書き込みは`SSID:<SSID>`の後に`PASS:<password>`を送ります。SSIDは最大32バイト、パスワードは最大63バイトです。状態Characteristicは`device_id`、`device_role: "child"`、`wifi_connected`、`provisioning_state`を含むJSONを返します。

## アプリの現状の制約

公開中のアプリ画面は親機設定用で、Wi-Fi接続後に状態JSONの`station_id`を要求し、そのIDをサーバーの親機として登録します。子機を誤って親機登録しないよう、このファームウェアは`station_id`を返しません。そのため、アプリからSSID・パスワードを書き込んで子機がWi-Fi接続することはできますが、アプリ画面は子機IDを親機IDとして登録せず、完了表示にはなりません。子機用の完了画面まで対応するには、アプリ側に子機設定フローが必要です。
